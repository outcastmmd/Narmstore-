### گزینه A: سرور مجازی ایرانی (پیشنهاد اصلی ✅)

| مورد | جزئیات |

| هزینه | ~۱۵۰ تا ۳۰۰ هزار تومان/ماه (~۲ تا ۴ دلار) |

| دیتابیس | PostgreSQL روی همان سرور — بدون انقضا |

**چرا این گزینه برای نرم‌استور بهترین است:**
- تنها گزینه‌ای است که با ریال و بدون دور زدن تحریم قابل پرداخت است
- هم مشکل انقضای دیتابیس حل می‌شود، هم cold start ~۲۵ ثانیه‌ای Render
- حجم دیتابیس فقط ۱۸MB است — حتی ضعیف‌ترین VPS هم کافی است
- دامنه `.ir` هم بعداً روی همین سرور ست می‌شود (مشکل فیلترینگ `onrender.com` حل می‌شود)

**ارائه‌دهنده‌های ایرانی VPS (نمونه):** پارس‌پک، آروان‌کلاد، لیزرهاست، ایران‌سرور.
حداقل مشخصات کافی: ۱ vCPU، ۱GB RAM، ۲۵GB دیسک.

## ۳. چک‌لیست مهاجرت (گزینه A: VPS ایرانی)

### فاز ۱ — آماده‌سازی (۱ روز)
- [ ] خرید VPS (اوبونتو ۲۲/۲۴، حداقل ۱GB RAM)
- [ ] اتصال SSH و به‌روزرسانی سیستم
- [ ] نصب PostgreSQL 16 و Node.js 20
- [ ] ساخت دیتابیس و کاربر `narmstore`

### فاز ۲ — انتقال دیتابیس (۱ ساعت)
- [ ] اجرای `drizzle-kit migrate` روی دیتابیس جدید (ساخت جدول‌ها)
- [ ] گرفتن بکاپ تازه: `node scripts/backup-cloud-db.mjs`
- [ ] اجرای restore روی VPS:
  ```bash
  DATABASE_URL="postgresql://narmstore:PASS@VPS_IP/narmstore" \
    node scripts/restore-cloud-db.mjs backups/narmstore-YYYYMMDDHHMM.json
  ```
- [ ] بررسی تعداد ردیف‌ها (باید با بکاپ یکی باشد: ۱۰۸۳ برنامه، ۱۵۶۱ نسخه و...)

### فاز ۳ — انتقال وب‌سرور (۲ ساعت)
- [ ] کلون ریپو روی VPS
- [ ] `npm install && npm run build`
- [ ] تنظیم متغیرهای محیطی (`DATABASE_URL` جدید، `SESSION_SECRET`)
- [ ] اجرای `next start` با process manager (مثل `pm2`)
- [ ] تنظیم reverse proxy (nginx) + HTTPS با Let's Encrypt

### فاز ۴ — سوییچ نهایی
- [ ] تست کامل سایت روی IP/دامنه موقت VPS
- [ ] تغییر DNS دامنه به VPS (اگر دامنه خریده شده)
- [ ] نگه داشتن Render به‌عنوان بکاپ به مدت ۱ هفته
- [ ] حذف سرویس Render بعد از اطمینان

## ۴. پلن بازگشت (Rollback)

اگر مهاجرت به مشکل خورد:

1. **دیتابیس Render هنوز زنده است** (تا 2027-01-14) — فقط `DATABASE_URL` را در Render به حالت قبل برگردان.
2. **بکاپ‌های روزانه** در `~/workspace/narmstore/backups/` موجودند (۷ نسخه آخر) — همیشه می‌توان روی هر دیتابیس تازه‌ای restore کرد.
3. **کد روی GitHub** است (`outcastmmd/Narmstore-`) — هیچ‌چیز گم نمی‌شود.

> قانون طلایی: تا وقتی سایت جدید ۴۸ ساعت بدون مشکل کار نکرده، Render را پاک نکن.
